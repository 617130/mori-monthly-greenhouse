# MORI / 一日温室

一个独立的每日记录小应用：每个日期对应一株植物，同一个月的植物会一起住进当月温室。每天完成日程会让植物获得成长点：0 级种子、1 级发芽、2 级幼苗、3 级长叶、4 级花苞，完成 5 件日程进入完全体；六种植物各自拥有不同的轮廓和花色。温室里的天气会在晴朗、多云、小雨和有风之间变化，偶尔会有小动物来串门。

## 使用

直接打开 `index.html` 即可。作品集首页的 MORI 卡片会链接到这里。

- 在“种下一件事”输入框按 Enter 添加任务。
- 可选具体时间、提醒方式和当天的植物种类。
- 点击圆形勾选完成任务；点击“编辑”可以修改或删除。
- 每天完成的日程数会直接决定植物等级（最多 5 / 5）；回顾文字和心情不会替代日程成长。
- “换一种天气”可以演示天气变化；温室会偶尔自动起风，植物随风摆动。
- 月份箭头可以切换不同温室；温室内的横向植物架展示该月每一天的植物，窗格、层架、吊藤和地面光影会随天气变化。
- 小动物会随机来访：松鼠找瓜子、小蜜蜂采蜜、蝴蝶绕着叶片飞，点击“召唤小动物”可以立即查看。
- “收集今天”保存心情、能量和一句回顾，植物会继续成长。

## 数据与提醒

- 数据保存在当前浏览器的 `localStorage`，无需账号。
- “本地数据”里可以导出或导入 JSON 备份。
- 系统通知需要在 `localhost` 或 HTTPS 下由用户主动授权。
- 页面内提醒会在页面打开时工作；关闭页面、设备休眠或移动端杀掉页面时，不保证送达。

项目不依赖框架或外部服务，适合直接作为静态页面使用。
